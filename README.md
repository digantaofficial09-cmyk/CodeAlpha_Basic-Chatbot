# CodeAlpha_Basic-Chatbot
A simple rule-based chatbot developed using Python for the CodeAlpha Internship. It responds to user inputs with predefined replies and demonstrates concepts like functions, loops, conditional statements, and user input handling through an interactive command-line conversation system.


##  Sample Run

```bash
====================================
        BASIC PYTHON CHATBOT
====================================

Type 'bye' to end the conversation.

You : hello
Bot : Hi! Nice to meet you.

You : how are you
Bot : I'm fine, thanks for asking!

You : what is your name
Bot : I am a simple Python chatbot.

You : bye
Bot : Goodbye! Have a great day.
